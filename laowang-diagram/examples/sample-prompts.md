# 提示词示例

## 一、跨角色泳道流程图（最常用）

```text
用 $laowang-diagram，绘制一张【电商退货退款】跨角色泳道流程图。涉及角色，买家、商家、平台客服、仓储系统。
必须包含，正常退货验收流程、卖家超时未处理自动退款、商品验收不合格拒收并引发客服介入 3 条分支逻辑。
输出为规范的 Mermaid flowchart 语法，并提供架构分层说明。
```

要点：把**角色**、**主干**、**异常**三类信息一次性给全。异常给得越具体，图越能用于评审。

## 二、带超时兜底的审批流程

```text
用 $laowang-diagram，画一张【费用报销审批】跨角色泳道流程图。角色：申请人、直属主管、财务、财务系统。
主干：申请人提交 → 主管审批 → 财务复核 → 打款。
异常：主管 24h 未审批自动升级至部门负责人；财务复核不通过退回申请人重新提交；打款失败自动重试 3 次后转人工。
输出 Mermaid 源码 + 分层说明，异常路径用虚线。
```

## 三、单角色主干流程（不套泳道）

```text
用 $laowang-diagram，画一张【用户注册登录】主干流程图，单角色，不用泳道。
步骤：手机号输入 → 验证码校验 → 密码设置 → 实名认证 → 进入首页。
异常：验证码错误 3 次锁定 10 分钟；实名认证失败可跳过但限制部分功能。
```

## 四、状态机图

```text
用 $laowang-diagram，画一张【订单状态流转】状态机图。
状态：待支付、已支付、已发货、已完成、已取消、退款中、已退款。
事件：支付成功、超时未支付、商家发货、确认收货、申请退款、退款成功。
标注每个状态的进入条件和终态。输出 Mermaid stateDiagram-v2。
```

## 五、时序图

```text
用 $laowang-diagram，画一张【下单支付】时序图。参与方：用户端、订单服务、支付网关、库存服务。
强调调用先后、同步/异步、以及支付回调超时的重试路径。输出 Mermaid sequenceDiagram。
```

## 六、要 draw.io 可编辑文件

```text
用 $laowang-diagram，按上面这张退货退款泳道图，额外导出一份 .drawio 文件。
要求用原生 swimlane 容器，每个角色一条泳道，节点可拖拽修改。
```

## 七、素材不全时（让它先追问）

```text
用 $laowang-diagram，我要画一张【供应商入驻审核】的流程图，但细节我还没想清楚，你先问我几个关键问题。
```

Skill 会按优先级一次问 1–3 个问题，不会一次甩十条。

## 八、常见补充指令

| 想做什么 | 加一句 |
|---|---|
| 换布局方向 | 「用 flowchart LR，泳道左右并列」 |
| 强调某条分支 | 「异常分支用红色虚线突出」 |
| 拆图 | 「节点超过 25 个就拆成主图 + 子图」 |
| 只要源码 | 「只给 Mermaid 源码，不要解释」 |
| 只要说明 | 「不用画图，先给我角色/主干/异常三份清单」 |
| 落盘 | 「产物写到 <目录>/，文件名用 主题_用途_日期_序号」 |
